## Más allá de la edición de código

VS Code tiene soporte integrado para _Markdown_, que permite formatear documentos usando una sintaxis de texto fácil de leer y escribir. Más allá del resaltado sintáctico y la vista previa (accesible vía `Shift+Ctrl+V` o `Shift+Cmd+V` en Mac), el soporte para este lenguaje ofrece mucho más que simple formato de documentos.

### Documentación y diagramas

Markdown es un excelente lenguaje para documentar tus proyectos, pero ¿qué pasa si necesitas crear diagramas y esquemas para explicar mejor tu código? ¡No te preocupes, hay muchas extensiones para eso!

Para todo lo relacionado con diagramas, ya sean diagramas de flujo, diagramas de secuencia, diagramas de clases, gráficos de Gantt, y más, la extensión **Markdown Preview Mermaid Support** es para ti. Te permite usar la sintaxis _Mermaid_ (https://mermaid.js.org) para incluir y visualizar tus diagramas directamente en tus documentos Markdown. Tus diagramas se definen usando una sintaxis textual en bloques de código clásicos y se mostrarán en la vista previa de Markdown.

![Ejemplo de diagrama de secuencia con Mermaid](./images/mermaid.png)

Si prefieres usar una herramienta de dibujo, la extensión **Draw.io Integration** te permite incrustar el editor en línea del mismo nombre en VS Code. Puedes entonces crear y editar tus diagramas directamente, sin salir de VS Code. Incluso cuando se exportan como SVG o PNG, tus diagramas permanecen editables manteniendo la extensión de archivo `.drawio.png` o `.drawio.svg` si activas la opción, ¡práctico!

Otra alternativa si te gustan los dibujos de pizarra es la extensión **Excalidraw**, que te permite crear dibujos vectoriales directamente en VS Code, manteniendo una apariencia "dibujada a mano" que puede ser muy atractiva para diagramas.

### Organización y notas

Además de la documentación, Markdown también es bastante útil para tomar notas y organizarse. La extensión **Dendron** te permite organizar tus notas en una base de conocimiento jerárquica y vincularlas a archivos de tu proyecto. La herramienta también está bien integrada en la búsqueda global de VS Code y usa la _navegación rápida_ para permitirte navegar a través de todas tus notas. Incluso puedes exportar tu base de conocimiento a un sitio web, para compartir con tus colegas.

Cuando se trata de organizar tu día a día, ya sea para el trabajo o la vida personal, la extensión **Todo Tree** es una herramienta muy práctica. Permite listar los `TODO` y `FIXME` de todos tus archivos y mostrarlos en una vista dedicada, con filtros y opciones de ordenamiento. Se acabaron los `// TODO: arreglar esto` que se acumulan y permanecen en tus archivos, esta extensión te permitirá encontrarlos y abordarlos fácilmente.

Y si, como yo, te gusta organizar tus ideas en mapas mentales, la extensión **Markmap** te permite crear mapas mentales simplemente con listas de Markdown, y navegar dentro de ellos directamente en VS Code.

![Ejemplo de mapa mental con Markmap](./images/markmap.png)

### Presentaciones

¡Puedes hacer casi cualquier cosa con Markdown, incluyendo presentaciones! La extensión **Marp for VS Code** permite crear presentaciones completas en Markdown, y exportarlas a PDF, HTML o PowerPoint. La extensión se basa en la herramienta _Marp_ (https://marp.app/), que también incluye varios temas básicos y la posibilidad de crear los tuyos propios en CSS.

Unas pocas líneas de markdown son suficientes para crear una presentación, y la extensión hará el resto.

![Ejemplo de presentación con Marp](./images/marp.png)

Como puedes ver, soy muy aficionado a Markdown, y su simplicidad y flexibilidad lo convierten en una herramienta muy práctica para acompañar el desarrollo de tus proyectos. Limitar el número de idas y vueltas entre VS Code y otras herramientas es a menudo un ahorro significativo de tiempo y productividad, así que no dudes en probar estas extensiones para ver si pueden ayudar en tus proyectos.
