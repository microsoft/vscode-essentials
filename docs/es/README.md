## Prólogo

"Es solo un archivo de texto." Sin embargo, este humilde archivo de texto tiene el potencial de convertirse en un sitio web, una aplicación móvil, un pipeline de datos o incluso un modelo de machine learning. Cuando comenzamos nuestro viaje en la programación, nuestras herramientas iniciales eran editores de texto "primitivos" como Notepad. Sin embargo, incluso el más pequeño punto y coma fuera de lugar podía llevar a una sesión de depuración frustrantemente larga. La evolución de las prácticas de desarrollo trajo consigo la era de los Entornos de Desarrollo Integrados (IDE), que, a pesar de ocupar gigabytes de espacio en disco y necesitar uno diferente para cada lenguaje de programación, ofrecían un amplio conjunto de funcionalidades para ayudar en el desarrollo: estado de compilación, autocompletado, resaltado de sintaxis, y más.

En respuesta, muchos buscaron crear editores de texto que fueran a la vez pequeños, ligeros y rápidos, pero que contaran con las funcionalidades avanzadas de un IDE. Con el tiempo, decenas de editores aparecieron, pero entonces llegó Visual Studio Code. Con el paso de los años, VS Code ascendió hasta convertirse en el [editor de texto preferido por la mayoría de los desarrolladores](https://survey.stackoverflow.co/2023/#section-admired-and-desired-integrated-development-environment), de forma similar a como Git se ha convertido en el estándar para el control de versiones.

Este libro está diseñado tanto para principiantes como para programadores experimentados, ofreciendo una exploración en profundidad de las capacidades de este editor y proporcionando información para aprovechar todo su potencial. Aunque no es exhaustivo, nuestro objetivo fue crear una guía concisa que pudiera leerse durante un trayecto diario, ofreciendo el máximo beneficio en el mínimo tiempo. Independientemente de tu stack tecnológico, VS Code probablemente ofrece la mejor configuración para tus necesidades.
