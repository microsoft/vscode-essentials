## La palabra final

Esperamos que hayas disfrutado este libro y que te haya dado ganas de explorar todo lo que es posible con VS Code. Hay muchas más funcionalidades y sería imposible cubrir todo aquí, ¡así que el resto es para que lo descubras!

Si quieres continuar tu aprendizaje, aquí tienes algunos recursos interesantes para ver (y seguir):
- [**Canal de YouTube de Visual Studio Code**](https://www.youtube.com/@code): El canal oficial de YouTube de Visual Studio Code contiene una gran cantidad de videos instructivos cortos, pero también organiza **eventos en vivo** donde puedes seguir e interactuar con la comunidad de VS Code.

- [**VS Code TikTok**](https://www.tiktok.com/@vscode): Si te gustó este libro de tamaño bocado, ¡te gustarán nuestros videos de tamaño bocado en TikTok! Montones de consejos rápidos que puedes usar en tu rutina diaria.
- ¿Buscas ayuda? Puedes hacer una pregunta en [Stackoverflow con la etiqueta `visual-studio-code`](https://stackoverflow.com/questions/tagged/visual-studio-code?tab=Newest)
- Si quieres estar al día, el [blog oficial](https://code.visualstudio.com/blogs) es una buena lectura y contiene información bastante interesante, y todas las notas de versión de las actualizaciones de Visual Studio Code están [disponibles en línea](https://code.visualstudio.com/updates) también.
