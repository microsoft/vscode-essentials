## Nuestras extensiones favoritas

Las extensiones te permiten personalizar VS Code según tu stack técnico. Realmente pueden facilitarte la vida y aumentar tu productividad. Antes de sumergirte en los cientos de extensiones disponibles, aquí está nuestra selección personal entre las que usamos a diario.

### Yohan

- **REST Client:** ¡mi herramienta favorita para probar APIs REST! Te permite definir solicitudes HTTP en un archivo de texto y ejecutarlas directamente desde VS Code.
- **Git Graph:** esencial para visualizar el historial y las ramas de Git y navegar fácilmente entre commits.
- **Prettier:** Para no tener que preocuparte más por formatear tu código, esta extensión lo hace automáticamente por ti.
- **Dev Containers:** esta extensión te permite definir, compartir y usar entornos de desarrollo en contenedores. ¡Se acabaron los problemas de dependencias y versiones!
- **GitHub Copilot:** ¡impulsa tu productividad con IA! Generación de código, pruebas, documentación, hoy no puedo prescindir de esta extensión. (Requiere suscripción)
- **PlatformIO IDE:** más que una simple extensión, transforma VS Code en un IDE completo para desarrollar aplicaciones para microcontroladores. Si te gusta Arduino, ¡te va a encantar!
- **Todo Tree:** si, como yo, abusas de los TODOs en tu código, esta extensión te permitirá agruparlos en una ventana dedicada, para no olvidarlos.
- **Microsoft Edge Tools for VS Code:** si desarrollas aplicaciones web, esta extensión te permitirá probar y depurar tus aplicaciones directamente en VS Code, sin tener que ir y venir entre tu navegador y tu IDE.
- **EditorConfig:** ¿tabulaciones o espacios? ¿2 o 4? Esta extensión te permite definir el formato básico de los archivos y compartirlo con otros desarrolladores.
- **Material Icon Theme:** para agregar un poco de color y distinción en el árbol de archivos, este tema de íconos es mi favorito.

### Christopher

- **Live Share:** esta extensión permite que varias personas colaboren en un proyecto abierto en la estación de trabajo de una persona. Una herramienta esencial para equipos remotos, revisión de código con varias personas, formación.
- **Polyglot Notebooks:** ¿necesitas escribir un pequeño script? ¿Probar un fragmento de código? Los notebooks políglotas te permiten hacer todo esto, y mucho más.
- **SQL Database Projects:** si trabajas con Azure SQL / SQL Server, esta extensión te permite versionar y desplegar tu esquema de base de datos de forma sencilla.
- **PostgreSQL:** si usas PostgreSQL, esta extensión te permite editar y ejecutar tu código SQL en tus servidores directamente desde VS Code.
- **GitHub Actions:** como su nombre indica, te permite ver y lanzar tus workflows de GitHub Actions directamente desde VS Code. ¡Commit, push y deploy en un abrir y cerrar de ojos!
- **Better Comments:** ¡los comentarios son vida! Pero entre `TODO`, comentarios de código, preguntas para la persona que hace la revisión de código, ¿cómo gestionarlo?
- **C# Dev Kit:** VS Code te permite trabajar en proyectos .NET con la extensión C#. Pero la extensión C# dev kit (que requiere una licencia - **gratuita para desarrolladores individuales, estudiantes y código abierto) aporta soporte para soluciones de Visual Studio, herramientas de refactorización, completado de código y pruebas avanzadas.
- **Conventional Commits:** nombrar una variable puede ser complicado, pero escribir un mensaje de commit puede serlo aún más. Esta extensión te permite seguir una convención de nomenclatura para tus mensajes de commit (https://www.conventionalcommits.org/).
- **Live Preview:** no es raro usar VS Code para desarrollar código HTML. Live Preview te permite tener un servidor HTTP para visualizar tu código directamente en VS Code, o en tu navegador favorito.
- **VS Code Pets:** si, como yo, trabajas en remoto, tus días pueden ser un poco monótonos. VS Code Pet te permite tener un compañero digital en VS Code: Perro, Gato, Pato de goma... ¡Incluso puedes lanzarle una pelota! Si no, siempre puedes salir a tomar un descanso real ;)
